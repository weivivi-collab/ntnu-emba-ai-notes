# NTNU EMBA · Industry Analysis

台師大 EMBA 產業分析課程  
architect: prof. shihmin Lo

依兩張手寫筆記重整的中英雙語互動網站與直式 SVG。內容包含 MVP／IRS、市場回饋、BMC／VP／TA／TAM、創新擴散與鴻溝、PM／PjM／KSA、AI 互動方式及 Input → Process → Output。

## 使用
- 直接開啟 `index.html`，或透過 GitHub Pages 瀏覽。
- 點擊章節展開；調整 MVP 滑桿、TAM 試算，或切換採用者、角色與 AI 工作層次。
- 頂端可切換繁體中文／English，操作狀態與個人筆記保留。
- 個人筆記僅儲存在此瀏覽器，可匯出文字備份；不會上傳或自動修改公開課程內容。
- `system-map.svg` 為純向量直式系統圖，含標題與無障礙描述。
- `source-notes.md` 記錄原稿判讀、待確認項目與編輯重整範圍。

## GitHub Pages
將本資料夾檔案放於儲存庫根目錄，在 Settings → Pages 使用 Deploy from a branch，選擇 main 分支與 /（root）。之後將檔案更新提交到 main，Pages 即會重新部署。網站使用相對路徑，不需建置、套件、API 金鑰或後端。

## 更新內容
`index.html` 是靜態內容；`styles.css` 是響應式樣式；`app.js` 處理雙語、互動與本機筆記。更新時一併維護兩種語言。修改 SVG 後也請更新 `source-notes.md` 中相應判讀。

市場數字均為示意演算。工具名稱依手寫筆記保留，不表示現行正式產品命名、功能、價格或安全保證。本頁為個人課程學習整理，非校方官方網站。
